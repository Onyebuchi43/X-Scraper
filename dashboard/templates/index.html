VPS & Production Deployment

Run campaigns 24/7 in the cloud without keeping your local PC open, and prepare your app for production with a custom domain.

🌐 Server Node & Health Monitor
📦 Production Setup & Custom Domain Guide

1. Will campaigns run when my PC is off?

Yes! When you deploy this application to a Virtual Private Server (VPS) such as DigitalOcean, AWS EC2, Hetzner, Vultr, or Linode, the server runs continuously 24 hours a day, 7 days a week. All active campaigns and scraping threads run on the VPS background scheduler.

2. Does it need a production database?

Currently, the application runs on a single-file SQLite database (dashboard.db), which works fine on a VPS filesystem. For publishing to a custom domain with high traffic, set the DATABASE_URL environment variable (e.g. postgresql://user:pass@host:5432/dbname) on your VPS to automatically enable production-grade PostgreSQL storage.

3. Production Deployment Commands (Copy & Run on VPS) 

# 1. Clone your repo on VPS
git clone https://github.com/yourusername/Scweet.git
cd Scweet

# 2. Create virtual environment & install requirements
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 3. Launch 24/7 background service with Gunicorn / Flask
nohup python3 -m dashboard.app > app.log 2>&1 &
